# AI Product Manager Interview Prep

## Common Interview Questions

### Product Sense
1. **How would you decide which AI features to build?**
   - Framework: Impact vs Feasibility matrix
   - Consider: data availability, model maturity, user value, risk

2. **How do you measure success for an AI product?**
   - Task-specific metrics (accuracy, precision, recall)
   - User metrics (engagement, task completion, satisfaction)
   - Business metrics (revenue, cost savings, retention)

3. **When should you NOT use AI?**
   - When rules-based logic is sufficient
   - When explainability is legally required
   - When training data has known biases
   - When the cost outweighs the benefit

### Technical Understanding
| Topic | What to Know |
|-------|-------------|
| LLMs | Transformers, tokens, context windows, fine-tuning vs RAG |
| Computer Vision | CNNs, object detection, image segmentation |
| NLP | Embeddings, sentiment analysis, named entity recognition |
| MLOps | Model versioning, A/B testing, monitoring, drift detection |
| Data | Feature engineering, labeling, annotation, quality metrics |

### System Design
- Design a recommendation engine for [Netflix/Spotify/Amazon]
- Design a fraud detection system
- Design a chatbot for customer support
- Design a content moderation pipeline

## Frameworks
- **RICE**: Reach, Impact, Confidence, Effort
- **HEART**: Happiness, Engagement, Adoption, Retention, Task success
- **Jobs-to-be-Done**: What job is the user hiring this AI to do?
